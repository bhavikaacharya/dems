# 💎 Diamond Employee Management System (DEMS)

A modern **Employee Management System** built using **HTML, CSS, and
JavaScript** with a professional admin dashboard UI for managing
employees, attendance, payroll, production, and reports.

The project is a frontend-based web application and is deployed using
**GitHub Pages**.

## ✨ Features

### 📊 Dashboard

-   Total employees overview
-   Present employees count
-   Production status
-   Pending tasks
-   Weekly attendance overview
-   Recent activities
-   Department distribution
-   Search functionality

### 👥 Employee Management

-   Employee listing
-   Employee ID and department information
-   Contact details
-   Salary type
-   Employee status
-   Search employees
-   Department filtering
-   Pagination
-   Add new employee

### 🕒 Attendance Management

-   Select attendance date
-   Mark employee attendance
-   Present / Absent / Half-day / Unmarked status
-   Attendance notes
-   Attendance summary
-   Save attendance records

### 💰 Payroll Management

-   Total payroll summary
-   Fixed salaries
-   Daily wages
-   Piece-based payments
-   Employee-wise payroll information
-   Gross pay
-   Deductions
-   Net pay
-   Payroll period selection
-   Export option

### 📈 Reports

The system includes multiple management reports:

-   **Attendance Report**
    -   Average attendance rate
    -   Total working days
    -   Most absent department
    -   Perfect attendance
    -   Weekly trend
    -   PDF download option
-   **Production Report**
    -   Diamonds processed
    -   Completion rate
    -   Quality pass rate
    -   Top-performing department
    -   Weekly output
    -   PDF download option
-   **Payroll Summary**
    -   Total disbursed
    -   Average salary
    -   Pending payments
    -   Overtime paid
    -   Monthly payroll
    -   PDF download option
-   **Department Performance**
    -   Department-wise performance percentages
    -   PDF download option

## 🎯 Project Objective

The objective of DEMS is to provide a centralized and easy-to-use
interface for handling common employee management operations such as:

-   Employee records
-   Attendance
-   Payroll
-   Production tracking
-   Department performance
-   Management reports

The system combines these modules into a single admin dashboard for a
more organized workflow.
